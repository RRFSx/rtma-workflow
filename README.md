# ar-workflow

Workflow for the Atmospheric River Prediction System (AR-PS)

### Currently supported platforms
-   NOAA RDHPCS Hera
-   NOAA RDHPCS Ursa
-   NOAA RDHPCS Gaea C6
-   MSU-HPC systems (Hercules/Orion)
-   NCAR supercomputer Derecho

## Check more information at [the wiki page](https://github.com/AR-PS/ar-workflow/wiki)
