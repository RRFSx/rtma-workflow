# wx-workflow

Workflow for the Atmospheric River Prediction System (**AR-PS**), Three-dimensional Real-Time Mesoscale Analysis (**RTMA**), and Rapid Refresh Forecast System (**RRFS**) v2.

### Currently supported platforms
-   NOAA RDHPCS Hera
-   NOAA RDHPCS Ursa
-   NOAA RDHPCS Gaea C6
-   MSU-HPC systems (Hercules/Orion)
-   NCAR supercomputer Derecho
-   WCOSS2

## Check more information at [the wiki page](https://github.com/AR-PS/wx-workflow/wiki)
